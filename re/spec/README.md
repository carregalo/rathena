# Especificações

Escritas a partir do código do rAthena, de capturas de tráfego e da análise do cliente, com palavras próprias.

- `server/` — mapa do código do rAthena: módulos, o que o jogo novo mantém, remove ou muda.
- `protocol/` — pacotes usados pelo jogo, com layouts gerados a partir do código do servidor.
- `client/` — comportamento do cliente: fluxos, ritmos, câmera, sprites, mapas, interface.
